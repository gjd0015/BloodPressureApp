# 🩺 血压健康管家 (BloodPressureApp)

> **纯本地离线安卓 App (uni-app / Vue 驱动)**  
> 专为鱼跃、欧姆龙、九安等主流数码管电子血压计定制，支持**拍照智能识别**与**纯手动录入**，数据 100% 存放在手机本地，保护绝对隐私，零网络依赖。

---

## 🌟 核心功能亮点

1. **拍照智能识别 (纯离线 OCR)**：
   - 拍照或从相册选图，自动定位液晶数码管区域；
   - 毫秒级识别 **高压 (收缩压)**、**低压 (舒张压)** 与 **脉搏 (心率)**；
   - 自动获取照片上传/拍摄时间作为默认测量时间；
   - 弹出交互核对卡片，照片与识别结果并排对照，支持微调确认后一键保存。

2. **全流程手动记录**：
   - 支持不上传照片，直接点击“手动记一笔”；
   - 自由选择测量日期、时间、场景标签（晨起静息、睡前、饭前、饭后、服药后等）及医生/用药备注。

3. **权威健康等级智能判定**：
   - 严格依照 **《中国高血压防治指南》** 阶梯标准：
     - 理想血压 (<120 / <80 mmHg, 绿色)
     - 正常高值 (120~139 / 80~89 mmHg, 黄色)
     - 1级轻度高血压 (140~159 / 90~99 mmHg, 橙色)
     - 2级中度高血压 (160~179 / 100~109 mmHg, 红色)
     - 3级重度高血压 (≥180 / ≥110 mmHg, 高危深红)
     - 单纯收缩期高血压 / 低血压
   - 配备实时脉搏状态（正常 / 心动过缓 / 心动过速）与日常护理建议。

4. **双轨趋势折线图**：
   - 纯本地 HTML5 Canvas 高性能流畅折线渲染；
   - 高压 (警戒线 140) 与低压 (警戒线 90) 双轨对比，支持触控拾取任意数据点。

5. **离线表格一键导出 (CSV / Excel)**：
   - 一键生成标准 UTF-8 BOM CSV 文件，手机/电脑 Excel 打开完全不乱码；
   - 便于随时就诊时向医生出示完整病历与早晚血压趋势。

## 🚀 如何在电脑中运行与打包 APK

本项目已完整配置，完美适配您电脑中已安装的 **HBuilderX (`D:\HBuilderX`)**：

### 方式一：一键快捷打开
直接双击项目根目录下的 **`open_in_hbuilderx.bat`** 即可自动启动 HBuilderX 并打开本项目。

### 方式二：手动在 HBuilderX 中打开
1. 打开 **HBuilderX**；
2. 顶部菜单点击 **文件 (File)** → **打开目录 (Open Directory)**；
3. 选择目录：`E:\ai娱乐项目\驾照学习\BloodPressureApp`；
4. 即刻完成载入。

## 📱 运行与打包说明

### 1. 电脑端即时预览
- 点击顶部菜单 **运行** → **运行到内置浏览器**；
- 即可在电脑屏幕上直接交互体验拍照解析、手动记录、折线图与导出功能。

### 2. 生成安卓手机安装包 (APK)
- 点击顶部菜单 **发行** → **原生App-云打包**；
- 选择 **Android (apk包)**；
- 勾选 **使用公共测试证书**；
- 点击 **打包**，等待几十秒即可下载得到标准的 `.apk` 安装文件，直接安装到任意安卓手机上即可使用！
